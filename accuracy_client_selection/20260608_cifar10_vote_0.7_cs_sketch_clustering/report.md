## 5. Communication & Ciphertext Details / 通信与密文计算详情

| 2 | Ciphertext Size / 密文大小 | `sum(len(ct.serialize()) for ct in encrypted_update.values())` |
| 3 | Ciphertext Blocks / 密文块数 | `sum(len(v) for v in encrypted_update.values())` |

### 5.3 Prefetch Communication Analysis / 预取通信分析

- **Total Upload / 总上传开销:** 18729.79 MB — 所有选中客户端密文上传的累计量
- **Fetch Volume (FV) / 补下载量:** 380.91 MB — 选中客户端实际 fetch 下载量（已扣除预取覆盖部分）
- **Training Communication (TV) / 训练通信:** 19110.70 MB = Upload(18729.79 MB) + FV(380.91 MB)
  ✅ 验证通过: Upload(18729.79 MB) + FV(380.91 MB) = TV(19110.70 MB)
  — TV 对齐 FedFetch 论文定义：TV = Upload + FV（不含后台预取）
- **Prefetch Broadcast / 预取广播:** 24971.76 MB — 服务器向未选中客户端后台广播的密文增量
- **Prefetch Download / 预取下载:** 24971.76 MB — 未选中客户端后台接收的密文增量
- **Prefetch + Fetch + Broadcast / 后台总流量:** 50324.42 MB = Prefetch DL(24971.76) + Fetch DL(380.91) + Broadcast(24971.76)
- **Effective Download / 理论下载责任:** 1306.73 MB — 每轮 delta_size × 选中客户端数（预取节省率计算基准）
- **Prefetch Savings / 预取节省:** 925.82 MB — Effective Download 与实际 FV 的差值
- **Baseline (no prefetch) / 无预取基线:** 1306.73 MB — 完整模型下载(1.05 MB × 1250 次)

> **Note / 说明:**
> 1. **FV** = 选中客户端实际 fetch 下载量。TV = Upload + FV（FedFetch 论文定义）。
> 2. **Effective Download** = delta_size × 选中客户端数，是理论下载责任，仅用于计算预取节省率。
> 3. **Prefetch** = 后台/空闲时流量，不计入 TV，但计入物理总下行带宽。
> 4. 预取的核心优势是**将训练前的同步下载变为后台增量推送**，降低 wall-clock 延迟。

## 6. Conclusion / 结论

- **Privacy / 隐私性:** 本实验采用 **CKKS 同态加密** 实现隐私保护联邦学习，服务器始终无法访问客户端原始模型更新。
- **Accuracy / 准确率:** 经过 **50** 轮训练，最终测试准确率达到 **77.03%**，测试损失为 **0.6721**。
- **Communication Overhead / 通信开销:** CKKS 密文引入 **14.33x** 的通信膨胀率。
- **Encryption Cost / 加密开销:** 平均每轮每个客户端加密耗时 **0.217s**。
- **Prefetch / 预取优化:** 启用 **CipherFetch (FedFetch-style)** 密文预取机制。
- **Training Communication / 训练通信:** 总训练通信 **19569360.06 KB**（上传 19179307.31 KB + 下载 390052.75 KB）。
- **Download Saved / 节省下载:** 选中客户端避免完整模型下载，共节省 **948042.95 KB**.
