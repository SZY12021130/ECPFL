# SAMK（TDSC 2025）端到端实验结果

- 模式：**synthetic**
- BFV：N=1024，log Q=61，t=2^40，Δ=2097074
- Paillier：512 bit，打包槽宽 65 bit，每密文 7 个点
- 加密维度 d=1024，分块数 1
- 密钥生成（Setup+KeyGen）：0.21s
- 每客户端平均加密耗时：0.21s
- 总上行 0.94 MB / 总下行 0.39 MB
- 解密最大绝对误差：3.61e-05

## 实现与依赖（密码学库）

- **不使用任何第三方密码学库**：未依赖 phe / tenseal / Pyfhel / sympy，全部自研实现（保证与项目 `ckks_fed/eshe.py` 同源的环算术）。
- BFV：纯 Python + NumPy；环 R_Q = Z_Q[X]/(X^N+1) 复用项目自研 `ckks_fed/eshe.py:RingContext`（双素数 CRT + negacyclic NTT，Q≈2^61）。
- Paillier：纯 Python 大整数实现（g=N+1 加速、同态乘法聚合、自定义 Miller-Rabin 素数生成）。
- 拉格朗日插值：NumPy 向量化 + 预计算插值矩阵（Z_q 上精确恢复）。
- 运行环境：Python 3.13.5，NumPy 2.1.3。
