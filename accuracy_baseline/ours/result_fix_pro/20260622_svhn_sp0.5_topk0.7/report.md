- **Fetch Volume (FV) / 补下载量:** 556.87 MB — 选中客户端实际 fetch 下载量（已扣除预取覆盖部分）
- **Training Communication (TV) / 训练通信:** 32437.21 MB = Upload(31880.34 MB) + FV(556.87 MB)
  ✅ 验证通过: Upload(31880.34 MB) + FV(556.87 MB) = TV(32437.21 MB)
  — TV 对齐 FedFetch 论文定义：TV = Upload + FV（不含后台预取）
- **Prefetch Broadcast / 预取广播:** 42385.75 MB — 服务器向未选中客户端后台广播的密文增量
- **Prefetch Download / 预取下载:** 42385.75 MB — 未选中客户端后台接收的密文增量
- **Prefetch + Fetch + Broadcast / 后台总流量:** 85328.38 MB = Prefetch DL(42385.75) + Fetch DL(556.87) + Broadcast(42385.75)
- **Effective Download / 理论下载责任:** 2238.13 MB — 每轮 delta_size × 选中客户端数（预取节省率计算基准）
- **Prefetch Savings / 预取节省:** 1681.26 MB — Effective Download 与实际 FV 的差值
- **Baseline (no prefetch) / 无预取基线:** 2238.13 MB — 完整模型下载(1.79 MB × 1250 次)

> **Note / 说明:**
> 1. **FV** = 选中客户端实际 fetch 下载量。TV = Upload + FV（FedFetch 论文定义）。
> 2. **Effective Download** = delta_size × 选中客户端数，是理论下载责任，仅用于计算预取节省率。
> 3. **Prefetch** = 后台/空闲时流量，不计入 TV，但计入物理总下行带宽。
> 4. 预取的核心优势是**将训练前的同步下载变为后台增量推送**，降低 wall-clock 延迟。

## 6. Conclusion / 结论

- **Privacy / 隐私性:** 本实验采用 **CKKS 同态加密** 实现隐私保护联邦学习，服务器始终无法访问客户端原始模型更新。
- **Accuracy / 准确率:** 经过 **50** 轮训练，最终测试准确率达到 **95.11%**，测试损失为 **0.1904**。
- **Communication Overhead / 通信开销:** CKKS 密文引入 **14.24x** 的通信膨胀率。
- **Encryption Cost / 加密开销:** 平均每轮每个客户端加密耗时 **0.436s**。
- **Prefetch / 预取优化:** 启用 **CipherFetch (FedFetch-style)** 密文预取机制。
- **Training Communication / 训练通信:** 总训练通信 **33215704.41 KB**（上传 32645466.03 KB + 下载 570238.38 KB）。
- **Download Saved / 节省下载:** 选中客户端避免完整模型下载，共节省 **1721607.32 KB**.
