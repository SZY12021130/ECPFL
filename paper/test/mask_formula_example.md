# KGC 零和盲化掩码：Auto 模式数值例子

> **文档定位**：`paper/mask_formula_example.md`  
> **对应推导**：`paper/mask_formula.md` 的完整数值走查  
> **目标**：用一个极简但完整的三客户端例子，逐步验证 mask_formula.md 中所有公式的正确性，重点展示 **稀疏化场景下 TEE 补偿的必要性** 与 **无稀疏化场景下自动抵消** 的对比。

---

## 实验设定

| 参数 | 取值 | 说明 |
|:---|:---|:---|
| 客户端数 $n$ | 3 | Client 1, 2, 3 |
| 总参数 $m$ | 6 | 扁平化后 6 个浮点数 |
| Batch size $S$ | 2 | 每个 CKKS SIMD 密文装 2 个数 |
| Batch 总数 $J$ | 3 | $J = \lceil 6/2 \rceil = 3$ |
| 权重 | $w = [0.2, 0.3, 0.5]$ | 满足 $\sum w_i = 1$ |
| 掩码范围 $B$ | 10 | 分量在 $[-10, 10]$ 均匀采样 |
| 稀疏化策略 | TopK | `sparsity_rate = 0.5`，每客户端保留 top 1 batch |
| 轮次 $t$ | 0 | 首轮，全局残差 $R^{(-1)} = 0$ |

**Batch 索引定义：**
- Batch 0：参数索引 $[0, 1]$
- Batch 1：参数索引 $[2, 3]$
- Batch 2：参数索引 $[4, 5]$

---

## Phase 0：KGC 离线掩码生成

### Step 1：随机采样前 $n-1$ 个掩码

KGC 生成：

$$
b_1 = [1,\; -2,\; 3,\; -1,\; 2,\; 0] \in \mathbb{R}^6
$$

$$
b_2 = [3,\; 1,\; -2,\; 4,\; -1,\; 2] \in \mathbb{R}^6
$$

### Step 2：零和约束确定 $b_3$

$$
b_3 = -\frac{1}{w_3}\sum_{i=1}^{2} w_i b_i = -\frac{1}{0.5}\bigl(0.2b_1 + 0.3b_2\bigr)
$$

计算：

$$
0.2b_1 = [0.2, -0.4, 0.6, -0.2, 0.4, 0]
$$

$$
0.3b_2 = [0.9, 0.3, -0.6, 1.2, -0.3, 0.6]
$$

$$
\sum_{i=1}^{2} w_i b_i = [1.1, -0.1, 0, 1.0, 0.1, 0.6]
$$

解出：

$$
\boxed{b_3 = [-2.2,\; 0.2,\; 0,\; -2.0,\; -0.2,\; -1.2]}
$$

### Step 3：验证零和约束

$$
0.2b_1 + 0.3b_2 + 0.5b_3 = [0, 0, 0, 0, 0, 0] \quad \checkmark
$$

### Step 4：按 batch 切分

| Client | Batch 0 | Batch 1 | Batch 2 |
|:---|:---|:---|:---|
| 1 | $[1, -2]$ | $[3, -1]$ | $[2, 0]$ |
| 2 | $[3, 1]$ | $[-2, 4]$ | $[-1, 2]$ |
| 3 | $[-2.2, 0.2]$ | $[0, -2]$ | $[-0.2, -1.2]$ |

---

## Phase 1：客户端本地训练

全局模型初始值：

$$
\theta^{(0)} = [10,\; 20,\; 30,\; 40,\; 50,\; 60]
$$

各客户端本地训练后产生的梯度更新：

$$
g_1 = [1, -1, 2, -2, 1, -1], \quad g_2 = [2, 1, -1, 3, -2, 1], \quad g_3 = [-1, 2, 1, -1, 3, -2]
$$

**按 batch 切分：**

| Client | $g_{i,0}$ | $g_{i,1}$ | $g_{i,2}$ |
|:---|:---|:---|:---|
| 1 | $[1, -1]$ | $[2, -2]$ | $[1, -1]$ |
| 2 | $[2, 1]$ | $[-1, 3]$ | $[-2, 1]$ |
| 3 | $[-1, 2]$ | $[1, -1]$ | $[3, -2]$ |

---

## Phase 2：客户端掩码注入

### Client 1

$$
\tilde{g}_1 = g_1 + b_1 = [2, -3, 5, -3, 3, -1]
$$

Batch 化：$\tilde{g}_{1,0} = [2, -3]$，$\tilde{g}_{1,1} = [5, -3]$，$\tilde{g}_{1,2} = [3, -1]$

### Client 2

$$
\tilde{g}_2 = g_2 + b_2 = [5, 2, -3, 7, -3, 3]
$$

Batch 化：$\tilde{g}_{2,0} = [5, 2]$，$\tilde{g}_{2,1} = [-3, 7]$，$\tilde{g}_{2,2} = [-3, 3]$

### Client 3

$$
\tilde{g}_3 = g_3 + b_3 = [-3.2, 2.2, 1, -3, 2.8, -3.2]
$$

Batch 化：$\tilde{g}_{3,0} = [-3.2, 2.2]$，$\tilde{g}_{3,1} = [1, -3]$，$\tilde{g}_{3,2} = [2.8, -3.2]$

---

## Phase 3：客户端稀疏化（TopK）

每客户端按 $L_1$ 范数保留 top-1 batch：

| Client | 选中 Batch | 上传掩码 $\\mathcal{M}_i^{(0)}$ |
|:---|:---|:---|
| 1 | Batch 1 ($\\| [5,-3] \\|_1 = 8$) | $[0, 1, 0]$ |
| 2 | Batch 1 ($\\| [-3,7] \\|_1 = 10$) | $[0, 1, 0]$ |
| 3 | Batch 2 ($\\| [2.8,-3.2] \\|_1 = 6$) | $[0, 0, 1]$ |

**上传集合：**
- Batch 0：$S_0^{(0)} = \\emptyset$
- Batch 1：$S_1^{(0)} = \\{1, 2\\}$
- Batch 2：$S_2^{(0)} = \\{3\\}$

---

## Phase 4-5：加密上传与 TEE 解密

客户端上传各自选中 batch 的 CKKS 密文，TEE 解密后得到：
- $\hat{u}_{1,1} = [5, -3]$，$\hat{u}_{2,1} = [-3, 7]$，$\hat{u}_{3,2} = [2.8, -3.2]$

---

## Phase 6：TEE 明文聚合与掩码补偿

### Batch 0（无人上传）

$$
\\delta_0^{(0)} = [0, 0]
$$

### Batch 1（Client 1 + 2，子集聚合）

**原始聚合（含掩码）：**

$$
W_1^{(0)} = 0.2 + 0.3 = 0.5
$$

$$
\\delta_1^{(0), \\text{raw}} = 0.4 \\cdot [5, -3] + 0.6 \\cdot [-3, 7] = \\boxed{[0.2,\\; 3.0]}
$$

**拆分为目标项与掩码残差：**

$$
\\text{目标聚合} = 0.4g_{1,1} + 0.6g_{2,1} = 0.4[2,-2] + 0.6[-1,3] = \\boxed{[0.2,\\; 1.0]}
$$

$$
\\epsilon_1^{(0)} = 0.4b_{1,1} + 0.6b_{2,1} = 0.4[3,-1] + 0.6[-2,4] = \\boxed{[0,\\; 2.0]}
$$

验证：$[0.2, 1.0] + [0, 2.0] = [0.2, 3.0]$ ✓

**为什么残差不为 0？** 全局零和要求 $0.2b_{1,1} + 0.3b_{2,1} + 0.5b_{3,1} = [0,0]$，但 Client 3 未上传 batch 1，分母变为 $0.5$ 而非 $1.0$，约束被破坏。

**TEE 显式补偿：**

$$
C_1^{(0)} = \\epsilon_1^{(0)} = [0,\\; 2.0]
$$

$$
\\delta_1^{(0)} = [0.2, 3.0] - [0, 2.0] = \\boxed{[0.2,\\; 1.0]} = \\text{目标聚合} \\quad \\checkmark
$$

### Batch 2（仅 Client 3）

$$
\\delta_2^{(0), \\text{raw}} = 1.0 \\cdot [2.8, -3.2] = [2.8, -3.2]
$$

目标聚合 = $g_{3,2} = [3, -2]$，掩码残差 = $b_{3,2} = [-0.2, -1.2]$

$$
C_2^{(0)} = [-0.2, -1.2], \\quad \\delta_2^{(0)} = [2.8,-3.2] - [-0.2,-1.2] = \\boxed{[3.0,\\; -2.0]} \\quad \\checkmark
$$

## 对比：无稀疏化（strategy = "none"）

假设所有客户端上传全部 batch，同一 batch 1 的聚合：

$$
\\delta_1^{\\text{raw}} = 0.2[5,-3] + 0.3[-3,7] + 0.5[1,-3] = [0.6, 0.0]
$$

目标聚合 = $0.2g_{1,1} + 0.3g_{2,1} + 0.5g_{3,1} = [0.6, 0.0]$

掩码残差 = $0.2b_{1,1} + 0.3b_{2,1} + 0.5b_{3,1} = [0, 0.0]$

**残差严格为 0，TEE 无需补偿。**

---

## Phase 7-10：残差、压缩、更新、重加密

**残差累加**（首轮 $R=0$）：$\\hat{\\delta}_1 = [0.2, 1.0]$，$\\hat{\\delta}_2 = [3.0, -2.0]$

**二次 TopK**（保留 batch 2）：$\\mathcal{K}^{(0)} = \\{2\\}$

更新残差：$R_1^{(0)} = [0.2, 1.0]$（未选中，保留），$R_2^{(0)} = [0, 0]$（选中，清零）

**全局模型更新**：

$$
\\theta^{(1)} = [10, 20, 30, 40, 50+3.0, 60-2.0] = \\boxed{[10,\\; 20,\\; 30,\\; 40,\\; 53,\\; 58]}
$$

**TEE 重加密**：$\\tilde{c}_2^{(0)} = \\text{Enc}([3.0, -2.0])$，输出 mask = $[0, 0, 1]$

## 验证汇总

| 检查项 | 结果 | 状态 |
|:---|:---|:---|
| KGC 零和约束 | $\\sum w_i b_i = \\mathbf{0}$ | ✅ |
| Batch 1 稀疏化残差 | $\\epsilon_1 = [0, 2.0] \\neq 0$ | ⚠️ 需补偿 |
| Batch 1 补偿后 | $\\delta_1 = [0.2, 1.0] = \\text{目标}$ | ✅ 精确消除 |
| Batch 2 补偿后 | $\\delta_2 = [3.0, -2.0] = g_{3,2}$ | ✅ 精确消除 |
| 无稀疏化 Batch 1 | 残差自动为 $\\mathbf{0}$ | ✅ 无需补偿 |

**全部验证通过。**
